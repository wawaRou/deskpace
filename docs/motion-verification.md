# 手势与真机验证

DeskPace 的面板显示 T90，即从松手到走完剩余位移 90% 的时间。窗口何时能收到点击需要单独测量。以下记录均来自内建屏；换系统版本或显示器后，应在同一目标上重新比较原速与调速。

## 离线回归

在 macOS 上运行 `./Tests/verify-motion.sh --offline`。此模式不切换桌面，无需辅助功能权限。它用固定样本检查到位判定、倍率误差和每块显示器的重试间隔，适合本地开发和 CI。

## 真机回归

在装有 Xcode Command Line Tools 的 Mac 上，从菜单栏退出 DeskPace，给运行测试的终端授予辅助功能权限。让光标所在的显示器至少有两个相邻空间。进入项目目录后运行：

```sh
./Tests/verify-motion.sh
```

脚本编译一个带手势引擎的临时测试程序。它优先选下一个空间，没有时选上一个；也可传 `--previous` 或 `--next` 指定方向。测试会实际切换桌面，并尝试点击起始空间中的临时窗口。运行期间请让探针完成往返，手动切换桌面会影响事件计数。要测全屏 App 的点击等待时间，从该 App 所在的全屏空间开始。

| 场景 | 测试核对的结果 |
| --- | --- |
| 冷启动直接调速 | 在采集原速曲线前，先测 4× 回弹与 3× 切换，再与同场景的 1× 基线比较。 |
| 1×、3×、4× 往返 | 去程、回程分别对照同方向的原速 T90，检查偏快、偏慢及 3× 和 4× 的差异。回程另测当前空间变化和抬手后的点击等待时间。 |
| 接近落点 | 核对结束事件发出时距目标不超过 2 点，比较 85% 至 95% 的分段用时；冷启动的 4× 回程额外丢弃一次位置更新。 |
| 慢划、停住再松手 | 对比 1× 和 3× 的 T90，并确认到达相邻空间。 |
| 取消回弹 | 对比 1× 和 4× 的 T90，并确认到达起始空间。 |
| 反馈超时与恢复 | 丢弃一次收尾的全部合成位置更新，观察结束事件交还系统。在同一显示器上连续两次尝试失败，分别确认经过 1 次、2 次原速到位后才重试，并恢复所选倍率。 |
| 连续同向切换 | 有三个相邻空间时，在 A → B 的收尾尚余约一半位移时开始 B → C。核对两次手势的交接顺序、C 的最终位置，以及第二程相对于同一方向原速的 T90。 |
| 连续回切 | 在 3× 去程接近落点、系统仍报告起始空间时反向划动。核对去程结束事件先于回程开始、两次手势各交还一次，并检查回程 T90 和最终空间。 |

如需单独复测连续同向切换，运行 `./Tests/verify-motion.sh --chain`。它需要至少三个空间，结束后回到起始空间。

切换通过的条件是目标确已成为当前空间，且实测距离在 2 点内连续保持至少 35 毫秒。即使已测出 T90，超时仍判失败。

常规往返、预设曲线切换和回弹的倍率比较取三次实测的中位数，逐次核对落点及事件交接。倍率按同方向的原速 T90 除以所选倍率计算预期值，双向容差取预期值的 12% 与「一个刷新周期加 4 毫秒采样间隔」中的较大值。3× 和 4× 的耗时差至少应达到预期差值的一半。

## 反馈恢复修复后的实测

2026-11-21 在 macOS 27.2.1、内建屏、普通桌面上，分别向前后两个相邻空间运行了完整回归。下表取三次往返的中位数，时间单位为毫秒。点击均由回程的同一目标窗口接收。

| 去程方向 | 动画倍率 | 去程 T90 | 回程 T90 | 抬手后的点击等待时间 |
| --- | ---: | ---: | ---: | ---: |
| 下一个空间 | 1× | 304 | 307 | 947 |
| 下一个空间 | 3× | 100 | 103 | 330 |
| 下一个空间 | 4× | 74 | 77 | 256 |
| 上一个空间 | 1× | 305 | 305 | 956 |
| 上一个空间 | 3× | 99 | 100 | 339 |
| 上一个空间 | 4× | 74 | 73 | 262 |

两组测试都验证了连续两次反馈超时后恢复 3×。随后的连续回切各观测到两条结束事件，回程 T90 分别为 101、103 毫秒。

### 连续同向切换

在同一内建屏上，从第一个空间划向第二个，松手约 55 毫秒后开始划向第三个。修复前，第二程 T90 为 305–310 毫秒，结束事件由系统原样接收。中间空间仍在移动，抬手时第三个空间距中心可能超过一个空间的间距。

修复后以第二次手势开始时的位置判断桌面是否正向落点靠近。分别沿两个方向运行三空间专项回归，第二程原速 / 3× 的 T90 为 312 / 99 毫秒和 311 / 101 毫秒，两次都到达目标空间。另在第一程松手后约 20、55、110 毫秒发起第二次同向手势，第二程 T90 分别为 101、98、101 毫秒。

## 历史实测记录

以下数据来自 macOS 27.2.1 的内建屏。测试程序以相同的位移和松手速度切回同一个目标，并在真实桌面上逐帧读出位置。点击列记录目标窗口实际收到鼠标按下事件的时刻，包含每隔约 20 毫秒尝试一次点击的采样误差。

独立 App 获得辅助功能权限后，也记录了直接在触控板上完成的 11 次 3× 切换。走完 90% 位移的实测范围为 104–107 毫秒，中位数 105 毫秒。

| 目标 | 所选倍率 | 走完 90% 位移 | 目标窗口收到点击 |
| --- | ---: | ---: | ---: |
| 普通桌面 | 1× | 304 毫秒 | 941 毫秒 |
| 普通桌面 | 3× | 102 毫秒 | 332 毫秒 |
| 普通桌面 | 4× | 77 毫秒 | 257 毫秒 |
| 全屏 App 所在空间 | 1× | 301 毫秒 | 953 毫秒 |
| 全屏 App 所在空间 | 3× | 100 毫秒 | 333 毫秒 |
| 全屏 App 所在空间 | 4× | 77 毫秒 | 262 毫秒 |

0.1.2 在同一台 Mac 上复测了慢划和回弹。慢划收尾在 1× 和 3× 时分别用了 314 和 106 毫秒走完 90% 位移，停住再松手分别用了 312 和 104 毫秒。取消回弹在 1× 时用了 316 毫秒，在 4× 时用了 77 毫秒，两次都回到原桌面。

0.1.1 修复了接近目标桌面时先停顿、再滑完一小段的问题。旧版在另一组实测中提前约 175 点结束了手势。0.1.1 用每次切换的真实位移校准手势行程。复测中，约 2× 的四次触控板切换分别耗时 151–157 毫秒走完 90% 位移。结束手势时距落点为 0–1 点。

0.1.4 修复了连续回切时回程降到原速的问题。在 3× 下，去程松手后约 60、150、230 毫秒开始反向划动，均回到起始桌面。回程 T90 从修复前的约 310 毫秒缩短到约 100 毫秒。

## 兼容性与待验证配置

macOS 27.2.1 内建屏已有上述真机结果。macOS 26 已做 SDK 类型检查，仍需在真机上验证。构建脚本同时编译 arm64 和 x86_64，架构覆盖情况不能代替手势实测。

公开分发前，还需在外接屏上分别验证「显示器具有单独的空间」开启和关闭两种配置：将光标移到目标屏，比较普通桌面及全屏空间的切换、回弹、快速回切和点击等待时间。所有显示器共用同一个用户倍率。
