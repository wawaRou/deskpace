# 按 macOS 大版本验证系统接口的兼容性

设计时核查的公开 SDK 未提供调整四指横移收尾时长的接口。为保留原生桌面动画，DeskPace 使用 Quartz 手势事件，并在运行时加载读取空间位置和复制手势数据所需的私有接口。这个选择要求每次 macOS 大版本变更后重新验证行为。

最低系统版本设为 macOS 26。引擎在取得辅助功能授权且所需接口可用时才启动监听。识别到水平桌面手势后，会核对手势所在的显示器、空间顺序和位置；无法确认落点时，原手势交给系统处理。如果已开始调速但桌面没有响应，程序结束本次接管，让系统收尾。

显示器具有单独空间时，程序按显示器标识匹配空间列表；共享空间时使用系统的共享列表。构建成功、SDK 类型检查和实际手势验证分别记录。公开分发前的验证范围包括 macOS 26 与 27、内建与外接显示器、普通桌面及全屏空间。已测配置、待测配置和回归命令集中在[手势与真机验证](../motion-verification.md)。
