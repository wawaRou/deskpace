# 运行时加载私有接口，按 macOS 大版本复测

设计 DeskPace 时，公开 SDK 没有提供调整原生桌面收尾时长的接口。为保留系统绘制的收尾动画，DeskPace 在运行时加载私有接口，读取桌面位置并更新手势数据。接口不可用或桌面位移无法确认时由系统按原速收尾，因此每个 macOS 大版本都要上机复测。

## 考虑过的其他做法

- **向 Dock 进程注入代码，直接改动画时长。** 用户需要部分关闭系统完整性保护（SIP），安装门槛和风险都过高。

## 后果

- DeskPace 不限制最高系统版本。在还没复测的大版本上，接口缺失时会退回原速，但符号仍在、参数或返回值已经改变时，运行时识别不出来，可能导致错误行为甚至崩溃。[复测清单](../motion-verification.md#macos-大版本复测)
