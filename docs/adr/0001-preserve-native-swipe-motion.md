# 以原生四指横移的收尾动效为调速基准

用户希望频繁切换桌面时能更早点击目标窗口，同时保留跟手移动和松手后平滑减速的手感。因此，DeskPace 在每次手势开始时记下倍率，保留 macOS 跟手阶段的行为，只调整松手后的时间。

倍率使用连续滑块，范围为 1× 至 4×。1× 时由系统完成收尾。更高倍率下，引擎根据系统的结束或取消事件确定落点，再按显示器刷新节奏推进同一段手势，由 macOS 合成画面。引擎初始使用内建参考曲线，取得有效的 1× 轨迹后，在本次运行中按显示器、按切换或回弹分别更新曲线。

从 0.1.2 起，回弹与成功切换共用所选倍率。即使慢划或停住再松手，也依据系统事件选择落点。到位前持续读取目标空间的实际位置，用来校准剩余行程。连续回切时，系统报告的当前空间可能落后于画面；从 0.1.4 起，引擎还参考上一程的目标及其实际偏移，确定反向手势的起点。

普通桌面和全屏空间、内建屏和外接屏共用一个用户倍率。单次调速是否生效由屏幕和空间的位置反馈确认。面板报告实际动作、采用的倍率和 T90；目标窗口的点击等待时间通过单独的真机测试测量。[术语](../../GLOSSARY.md) · [验证方法和结果](../motion-verification.md)
