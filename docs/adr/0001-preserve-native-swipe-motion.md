# 以原生四指横移的收尾动效为调速基准

用户频繁切换桌面，希望抬手后更早就能点中新桌面上的目标，也在意横移时平滑减速到位的手感。以同一次原生切换为参照，理想效果相当于把从抬手到停稳的画面按选定倍率播放。

点开菜单栏图标即可看到当前倍率、连续滑块和「恢复原速」。调整后的倍率从下一次四指横移起生效，软件记住上次的设定。「恢复原速」将倍率设为 1×。

根据第一次真机试用反馈，原型把连续滑块的范围定为 1× 至 4×，便于直接比较较高倍率。面板分别显示所选倍率和上次切换的实测耗时。

普通桌面和全屏 App、内建屏和外接屏都共用同一个动画倍率。由 macOS 决定哪些屏幕响应本次手势。首版发布前须在外接显示器上实际验证四指切换时的收尾动效和等待时间。

如果松手后回到这次手势的起始空间，首版按系统原速回弹。等实际体验过，再决定回弹是否也采用滑块设定的倍率。

目标系统为 macOS 26 及以上版本，计划通过 GitHub 发布。
