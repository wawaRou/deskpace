# 保留原生四指横移，只调整收尾动画的速度

频繁切换桌面时，用户希望更早点击目标窗口，同时保留桌面跟手移动、松手后平滑减速的手感。DeskPace 保留系统的跟手阶段，松手后沿原生收尾曲线按所选倍率继续推进同一次手势，切换和回弹都由 macOS 绘制。直接跳到目标空间虽然更快，却会丢失这段连续的运动。

连续切换时，直接快进曲线会放大松手后前几帧的位移。加速切换以原生曲线的 T90 和停稳时间为准。起步速度取自原速记录，随后加速至匀速段，接近 T90 时减速，与最后 10% 的原生收尾衔接。从 1× 到 2× 逐渐混入这条曲线，2× 到 4× 使用完整曲线。取消向相邻空间的切换时，回弹使用同样的逐帧节奏，并依据原生回弹的 T90 和停稳时间。在桌面边界向外拖动时，位移与手指行程之间是非线性关系，这段弹性回弹交给系统处理。

首次刷新回调即使迟到，也只推进一个刷新周期。桌面位移更新得到确认后，后续每帧最多推进 1.03 个周期，逐步追上原定时间。偶发延迟可以使实测 T90 略晚，避免把漏掉的位移集中在一次更新里。

长划后立即松手时，最后一次触控更新可能还在等待显示。在发出第一个合成位置前，按最新桌面位置确定起点和行程比例；如果最后一笔位移刚刚发出、桌面位置还没变化，留一个刷新周期让它显示。

在加速倍率下，手指开始移动时就建立刷新回调，静止半秒后释放。上一次合成位移若尚未出现在桌面位置反馈中，可在同一帧的截止时间前延迟最多 2 毫秒再读一次。新的手势会取消旧手势的待处理更新。

跨多个桌面连续划动时，在同一显示器和同一桌面排列内记录已途经的桌面，允许系统报告的当前桌面短暂落后于画面。极早反向时，如果目标位置和手指方向仍不适合接管，这一程交给系统，并保留目标供下一程接续。
