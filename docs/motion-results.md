## 长帧、回弹与连续切换

2026-11-21 在 macOS 27.2.1、120 Hz 内建屏、低电量模式关闭的条件下，以相同的模拟四指手势比较 1×、1.99×、2.90× 和 4×。普通桌面矩阵覆盖双向切换、短划即松、长划即松、慢划、停住再松、取消回弹、连续回切和连续同向切换。此外用临时全屏窗口做了 32 程普通及长划往返。屏幕采样保留所有样本时间戳、空闲状态和重复画面，仅在内存里比较像素；另以约 1 毫秒轮询桌面位置。

| 场景 | 修正前 | 修正后 |
| --- | --- | --- |
| 长划即松，最后一笔位移晚于松手事件显示 | 四程中，每程在 T90 前最长的位置更新间隔，中位数为 1.99× **23.4**、2.90× **15.4**、4× **14.8** 毫秒 | 修正收尾起点后分别为 **8.9、9.3、9.0** 毫秒。1× 同场景约为 **9** 毫秒。 |
| 在最外侧桌面继续向外划 | 约 56 点的弹性位移一度缩至 2 点，随后再次放大，出现逐帧往返跳动。1.99× 和 2.90× 均复现 | 左右两个边界在四档倍率下均由系统接收原始取消事件，实测归位偏差为 0 点。 |
| 大幅划动后取消，4× | 拉出约 893 点、停 25 毫秒再松手，最大单次位置变化的三程中位数为 **153 点** | 回弹沿自己的原速曲线定时，采用与切换相同的平滑起步。最大单次变化降至 **99 点**，T90 从 **81** 变为 **83** 毫秒。 |
| A → B → C → B → A，连续重复两遍 | 每次松手约 55 毫秒便开始下一次手势。系统报告的当前桌面滞后，2.90× 和 4× 均有 4/8 程被交回原速 | 保留未完成连续手势经过的桌面范围，同样的两组均有 8/8 程接管，最终回到 A。极早反向时，目标若尚未越过画面中心且手势正在远离目标，仍交给系统处理这一程。 |

原速和调速都出现过约 16.7 毫秒的屏幕采样交付间隔。修正前的 125 程记录中，从松手到 T90 共计 141 个至少 14 毫秒的采样间隔，其中 140 个间隔内桌面位置仍有更新。另有 26 个完整样本的抽样像素没有明显变化，23 个样本标为空闲。采样漏帧与桌面停顿须分别判读。软件采样无法证明面板每一帧实际呈现的内容，外接屏及用户实际手势的主观体验仍需单独验证。

最终构建的普通桌面往返中，三组 4× 的 T90 为 73–83 毫秒，回程窗口在松手后 262–268 毫秒收到了点击。3× 慢划和停住再松手的 T90 分别为 108 和 110 毫秒。单独各复测六次，分别为 106–113 和 109–113 毫秒。

最后在 1.99×、2.90×、4× 各测两组跨三个桌面的连续八划。剩余 20% 路程时开始下一划的三组都八程加速。剩余 45% 时就开始下一划的三组中，4× 有一次极早反向由系统接手。六组都经过预期的中间桌面并回到起点。

## 1× 至 4× 连续回切的起步位移

2026-11-21 在 macOS 27.2.1 的 120 Hz 内建屏上，对比上一版平滑曲线与本次调整。每个倍率各做三次连续回切，去程走完约 80% 时开始反向划动。下表取回程中位数。首步为屏幕采样在松手后首次检测到的横移，较大步幅为同一程中间隔 7–10 毫秒的相邻画面位移的第 95 百分位。两版均由相同探针发出手势，实际松手距离会随手势交接略有变化。

| 倍率 | 首步位移，前 → 后（点） | 较大步幅，前 → 后（点） | 回程 T90，前 → 后（毫秒） |
| --- | ---: | ---: | ---: |
| 1× | 38 → 38 | 48 → 48 | 304 → 304 |
| 1.5× | 70 → 42 | 60 → 52 | 206 → 199 |
| 2× | 82 → 30 | 68 → 66 | 153 → 150 |
| 2.5× | 102 → 36 | 84 → 84 | 124 → 121 |
| 3× | 108 → 42 | 106 → 104 | 104 → 101 |
| 3.5× | 150 → 46 | 118 → 114 | 89 → 87 |
| 4× | 188 → 54 | 136 → 132 | 77 → 76 |

首步统计包括静止后首次更新，与上一个画面的时间间隔可能超过一个刷新周期。屏幕采样也可能漏掉更新，不能用于确认每次物理刷新。关闭屏幕采样后另做普通往返，每个倍率三次。回程点击等待时间中位数在 2× 为 485 → 483 毫秒，3× 为 330 → 330 毫秒，4× 为 259 → 269 毫秒。开启屏幕采样的另一轮，新版 4× 点击中位时间为 320 毫秒。完整真机回归覆盖了六档连续回切，以及连续同向切换三个空间，后者第二程 3× T90 为 105 毫秒。

## 约 2× 连续切换的帧位移（上一次优化）

2026-11-21 在 macOS 27.2.1 的 120 Hz 内建屏上，以 1.987× 对比原实现和平滑后的收尾曲线。两版各做五组相同的模拟四指手势。每组先在两个普通桌面间往返，再在去程松手 130 毫秒时反向划回。单独往返的松手距离约为 1345 点。

用屏幕采样中横向移动的画面内容估算帧位移，选取间隔为 7–10 毫秒的相邻样本。每程取松手至 T90 后一个刷新周期内的第 95 百分位位移，再取各程中位数。此指标描述较大的单帧跳步，长采样间隔不参与统计。

| 场景 | 原帧位移 | 新帧位移 | 原 T90 | 新 T90 |
| --- | ---: | ---: | ---: | ---: |
| 单独往返，十程 | 120 点 | 84 点 | 154 毫秒 | 153 毫秒 |
| 连续回切，五次回程 | 138 点 | 112 点 | 151.5 毫秒 | 152.3 毫秒 |

单独回程中，目标窗口收到点击的中位时间从 473 毫秒变为 479 毫秒，相差小于探针约 20 毫秒的点击尝试间隔。完整真机回归也通过了反馈超时恢复、回弹和连续同向切换；3× 连续回切的回程 T90 为 104 毫秒，连续切换三个空间的第二程为 101 毫秒。

## 反馈恢复修复后的实测

2026-11-21 在 macOS 27.2.1、内建屏、普通桌面上，分别向前后两个相邻空间运行了完整回归。下表取三次往返的中位数，时间单位为毫秒。点击均由回程的同一目标窗口接收。

| 去程方向 | 动画倍率 | 去程 T90 | 回程 T90 | 抬手后的点击等待时间 |
| --- | ---: | ---: | ---: | ---: |
| 下一个空间 | 1× | 304 | 307 | 947 |
| 下一个空间 | 3× | 100 | 103 | 330 |
| 下一个空间 | 4× | 74 | 77 | 256 |
| 上一个空间 | 1× | 305 | 305 | 956 |
| 上一个空间 | 3× | 99 | 100 | 339 |
| 上一个空间 | 4× | 74 | 73 | 262 |

两组测试都验证了连续两次反馈超时后恢复 3×。随后的连续回切各观测到两条结束事件，回程 T90 分别为 101、103 毫秒。

### 连续同向切换

在同一内建屏上，从第一个空间划向第二个，松手约 55 毫秒后开始划向第三个。修复前，第二程 T90 为 305–310 毫秒，结束事件由系统原样接收。中间空间仍在移动，抬手时第三个空间距中心可能超过一个空间的间距。

修复后以第二次手势开始时的位置判断桌面是否正向落点靠近。分别沿两个方向运行三空间专项回归，第二程原速 / 3× 的 T90 为 312 / 99 毫秒和 311 / 101 毫秒，两次都到达目标空间。另在第一程松手后约 20、55、110 毫秒发起第二次同向手势，第二程 T90 分别为 101、98、101 毫秒。

### 中途超时与边缘桌面复测

2026-11-21 在 macOS 27.2.1 内建屏的三个普通桌面上，探针先模拟松手后立即失去反馈，再模拟走完至少 10% 位移后失去反馈。修复前，第二次超时后的第一程仍被加速；修复后，分别观测到 1 次和 2 次原速到位，再恢复 3×。

从最右侧桌面运行 `--chain --next`，第二程原速和 3× 的 T90 分别为 307 和 103 毫秒。从最左侧运行 `--chain --previous`，分别为 304 和 103 毫秒。两个专项都回到了启动时的桌面。

## 历史实测记录

以下数据来自 macOS 27.2.1 的内建屏。测试程序以相同的位移和松手速度切回同一个目标，并在真实桌面上逐帧读出位置。点击列记录目标窗口实际收到鼠标按下事件的时刻，包含每隔约 20 毫秒尝试一次点击的采样误差。

独立 App 获得辅助功能权限后，也记录了直接在触控板上完成的 11 次 3× 切换。走完 90% 位移的实测范围为 104–107 毫秒，中位数 105 毫秒。

| 目标 | 所选倍率 | 走完 90% 位移 | 目标窗口收到点击 |
| --- | ---: | ---: | ---: |
| 普通桌面 | 1× | 304 毫秒 | 941 毫秒 |
| 普通桌面 | 3× | 102 毫秒 | 332 毫秒 |
| 普通桌面 | 4× | 77 毫秒 | 257 毫秒 |
| 全屏 App 所在空间 | 1× | 301 毫秒 | 953 毫秒 |
| 全屏 App 所在空间 | 3× | 100 毫秒 | 333 毫秒 |
| 全屏 App 所在空间 | 4× | 77 毫秒 | 262 毫秒 |

0.1.2 在同一台 Mac 上复测了慢划和回弹。慢划收尾在 1× 和 3× 时分别用了 314 和 106 毫秒走完 90% 位移，停住再松手分别用了 312 和 104 毫秒。取消回弹在 1× 时用了 316 毫秒，在 4× 时用了 77 毫秒，两次都回到原桌面。

0.1.1 修复了接近目标桌面时先停顿、再滑完一小段的问题。旧版在另一组实测中提前约 175 点结束了手势。0.1.1 用每次切换的真实位移校准手势行程。复测中，约 2× 的四次触控板切换分别耗时 151–157 毫秒走完 90% 位移。结束手势时距落点为 0–1 点。

0.1.4 修复了连续回切时回程降到原速的问题。在 3× 下，去程松手后约 60、150、230 毫秒开始反向划动，均回到起始桌面。回程 T90 从修复前的约 310 毫秒缩短到约 100 毫秒。
