# DeskPace v1.0.0 手势实测记录

2026-11-22，在 Apple 芯片 Mac 的内建屏上测试，系统为 macOS 27.2.1。探针模拟四指输入，记录系统收到的手势事件和桌面位置。表中的 T90 从松手开始计时，到桌面走完剩余位移的 90% 为止。[测试命令与通过条件](motion-verification.md)

## 没切完就反向划

去程桌面接近落点、系统仍报告起始空间时，立即反向划回。两轮测试的回程 T90 如下。

| 倍率 | 回程 T90（毫秒） |
| --- | --- |
| 2.9× | 107、111 |
| 4× | 77、78 |

探针在回程开始时和回程进入收尾后，各重发一次去程的位置更新。两个时点的更新均被拦截。另在 4× 下，把交付结束事件的唤醒信号延迟到下一划开始后，系统仍在回程开始前收到去程的结束事件。迟到的信号也没有让这个事件重复送达。

## 连续切换三个桌面

从 A 经 B 划向 C，再从 C 经 B 划回 A，重复两次，共八划。分别在 2.9× 和 4× 下测试，每档各测两个交接时机：离目标还剩 45% 或 20% 桌面间距时就开始下一划。两轮共 64 程，每次交接时系统都先收到上一划的结束事件，每组八划都回到了 A。

另测同向连划：B 还在移动时就从 B 划向 C，记录第二程的 T90。

| 所选倍率 | 同方向系统原速（毫秒） | 加速后（毫秒） |
| --- | ---: | ---: |
| 2.9× | 312 | 110 |
| 3× | 306 | 109 |
| 4× | 307 | 81 |

## 验证范围

本次构建包含 arm64 和 x86_64，手势真机测试使用 Apple 芯片 Mac 的内建屏。Intel Mac、macOS 26 和外接显示器上的手势体验仍待真机验证。
