## 快速连划时突然跳回

2026-11-21，在 macOS 27.2.1 的 120 Hz 内建屏上，对比提交 `095f745` 和修复后的 `5495f76`。这两次提交都晚于公开版 v0.1.6。屏宽 1512 点。探针模拟四指输入，同时记录手势事件、桌面位置和屏幕画面。每组连续划八次，覆盖同向跨三个桌面，以及两个桌面之间还没切完就反向。

修复前，下一划已经开始，系统仍可能收到上一划的位置更新。一次 4× 跨桌面连划中，画面横移约 665 点，8.3 毫秒后反向约 567 点。最终桌面正确。4× 下共记录到 16 次先跳远又跳回的异常，两段各超过 350 点，且在 38 毫秒内完成，每一次都对应一条迟到的旧位置更新。

| 场景 | 倍率 | 旧更新通过次数 / 交接次数（修复前） | 旧更新通过次数 / 交接次数（修复后） | 末程 T90 中位数，修复前 / 后（毫秒） |
| --- | ---: | ---: | ---: | ---: |
| 连续跨三个桌面 | 2.9× | 1 / 21 | 0 / 98 | 99 / 99 |
| 两个桌面未切完就反向 | 2.9× | 2 / 21 | 0 / 98 | 101 / 100 |
| 连续跨三个桌面 | 4× | 10 / 49 | 0 / 98 | 73 / 72 |
| 两个桌面未切完就反向 | 4× | 7 / 49 | 0 / 98 | 74 / 74 |

修复后的每个场景、每档倍率各做 14 组，松手后间隔 18 至 70 毫秒开始下一划。392 次交接中，没有旧位置更新串进下一划，桌面位置和屏幕样本中也没有再出现这种大幅跳回。报告问题的用户随后用触控板复测，确认原先的闪烁已消失。

作为对照，修复前在 1× 和 2× 各测了 42 次交接，这两批样本都没遇到错序。另在 4× 下做了 7 组手指始终贴着触控板的折返，每组折返八次。跟手期间没有合成位置更新，也没有测到大幅跳回。

## 长划松手、边缘回弹与三桌面连划

2026-11-21，提交 `095f745`，macOS 27.2.1，120 Hz 内建屏，低电量模式关闭。模拟手势覆盖短划、长划、慢划、停住再松手、取消回弹及连续切换。桌面位置约每毫秒读一次。屏幕样本保留时间戳、重复画面及空闲状态，像素只在内存中比较。另用临时全屏窗口测了 32 程普通及长划往返。

| 场景 | 修复前 | 修复后 |
| --- | --- | --- |
| 长划即松，最后一笔跟手位移延后显示 | 按四程取中位数，T90 前最长位置更新间隔在 1.99×、2.9×、4× 下分别为 23.4、15.4、14.8 毫秒 | 分别为 8.9、9.3、9.0 毫秒。1× 同场景约为 9 毫秒。 |
| 在最外侧桌面继续向外划 | 约 56 点的弹性位移一度缩至 2 点，随后再次放大。1.99× 和 2.9× 都能复现。 | 四档倍率下，左右边界都由系统按原速回弹，归位偏差为 0 点。 |
| 大幅划动后取消，4× | 拉出约 893 点，停 25 毫秒再松手。三程中，最大单次位移的中位数为 153 点，T90 为 81 毫秒。 | 最大单次位移降至 99 点，T90 为 83 毫秒。 |
| 从 A 经 B 划到 C 再原路返回，重复两遍 | 每次松手约 55 毫秒就开始下一划。2.9× 和 4× 各有四程退回原速。 | 同样两组均八程加速，最终回到 A。 |

另在 1.99×、2.9×、4× 各做两组连续八划。离目标还剩 20% 桌面间距时就开始下一划，三组均八程加速。还剩 45% 时就开始下一划，4× 有一次过早反向由系统收尾。六组都经过预期的中间桌面并回到起点。

普通桌面往返中，三组 4× 的 T90 为 73 至 83 毫秒，回程窗口在松手后 262 至 268 毫秒收到点击。3× 慢划和停住再松手的 T90 分别为 108 和 110 毫秒。各复测六次，范围分别为 106 至 113 和 109 至 113 毫秒。

**屏幕采样的限制。** 原速和调速时都出现过约 16.7 毫秒的采样间隔。修复前的 125 程中，从松手到 T90 一共出现 141 个至少 14 毫秒的采样间隔，其中 140 个间隔内桌面位置仍在更新。另有 26 个完整样本的抽样像素没有明显变化，其中 23 个标为空闲。仅凭相邻屏幕样本的间隔，无法判断面板是否停了一帧。

## 调整曲线后，连续回切的第一步有多大

2026-11-21，macOS 27.2.1，120 Hz 内建屏。去程走完约 80% 时反向划回。每个倍率各做三次，取回程中位数。第一步指松手后首次从屏幕样本中测到的横移，间隔可能超过一个刷新周期。较大步幅取间隔为 7 至 10 毫秒的相邻样本，按位移的第 95 百分位计算。两版使用相同的模拟手势，松手时的实际位置随交接时机略有变化。

| 倍率 | 第一步，调整前 / 后（点） | 较大步幅，前 / 后（点） | 回程 T90，前 / 后（毫秒） |
| --- | ---: | ---: | ---: |
| 1× | 38 / 38 | 48 / 48 | 304 / 304 |
| 1.5× | 70 / 42 | 60 / 52 | 206 / 199 |
| 2× | 82 / 30 | 68 / 66 | 153 / 150 |
| 2.5× | 102 / 36 | 84 / 84 | 124 / 121 |
| 3× | 108 / 42 | 106 / 104 | 104 / 101 |
| 3.5× | 150 / 46 | 118 / 114 | 89 / 87 |
| 4× | 188 / 54 | 136 / 132 | 77 / 76 |

关闭屏幕采样后另做普通往返，每个倍率三次。回程点击等待时间的中位数在 2× 从 485 变为 483 毫秒，3× 两版均为 330 毫秒，4× 从 259 变为 269 毫秒。开启屏幕采样的另一轮，调整后 4× 的中位数为 320 毫秒。完整回归也覆盖了六档连续回切和同向切换三个空间，后者第二程在 3× 下的 T90 为 105 毫秒。

### 早期的 1.987× 对照

同日、同一系统和屏幕。调整曲线前后各做五组相同的模拟手势。每组先独立往返，再在去程松手 130 毫秒时反向划回。独立往返时，松手后还剩约 1345 点。每程取松手至 T90 后一个刷新周期内、间隔为 7 至 10 毫秒的画面样本，计算位移的第 95 百分位，再取各程中位数。

| 场景 | 较大步幅，前 / 后（点） | T90，前 / 后（毫秒） |
| --- | ---: | ---: |
| 独立往返，十程 | 120 / 84 | 154 / 153 |
| 连续回切，五次回程 | 138 / 112 | 151.5 / 152.3 |

独立回程的点击等待时间中位数从 473 变为 479 毫秒，相差小于约 20 毫秒的点击尝试间隔。这轮完整回归通过了反馈超时恢复、回弹和连续同向切换。3× 连续回切的回程 T90 为 104 毫秒，同向切换三个空间的第二程为 101 毫秒。

## 位置反馈超时后恢复加速

2026-11-21，macOS 27.2.1，内建屏，普通桌面。分别向前、向后各运行一次完整回归。表中时间均为三次往返的中位数，点击由回程的同一目标窗口接收。

| 去程方向 | 倍率 | 去程 T90（毫秒） | 回程 T90（毫秒） | 回程点击等待时间（毫秒） |
| --- | ---: | ---: | ---: | ---: |
| 下一个空间 | 1× | 304 | 307 | 947 |
| 下一个空间 | 3× | 100 | 103 | 330 |
| 下一个空间 | 4× | 74 | 77 | 256 |
| 上一个空间 | 1× | 305 | 305 | 956 |
| 上一个空间 | 3× | 99 | 100 | 339 |
| 上一个空间 | 4× | 74 | 73 | 262 |

分别在松手时和走完至少 10% 位移时丢弃后续位置更新。修复前，第二次超时后的第一程仍被加速。修复后，两次超时分别等到一次、两次原速到位才恢复 3×。随后两个方向的连续回切均收到预期的两条结束事件，回程 T90 分别为 101、103 毫秒。

同向连划时，从第一个空间划向第二个，松手约 55 毫秒后再划向第三个。修复前，中间桌面仍在移动，第三个空间离中心可能超过一个桌面间距。第二程退回原速，T90 为 305 至 310 毫秒。修复后，两个方向的第二程 T90 分别从原速的 312、311 毫秒降到 3× 的 99、101 毫秒。把两划间隔改为约 20、55、110 毫秒，第二程 T90 分别为 101、98、101 毫秒。

从最右侧桌面运行 `--chain --next`，第二程 T90 在原速和 3× 时分别为 307 和 103 毫秒。从最左侧运行 `--chain --previous`，分别为 304 和 103 毫秒。两次都返回启动时的桌面。

## 早期版本的普通桌面和全屏测试

macOS 27.2.1，内建屏。程序用相同的位移和松手速度切回同一目标，约每 20 毫秒尝试点击一次。另用触控板手动完成 11 次 3× 切换，T90 为 104 至 107 毫秒，中位数 105 毫秒。

| 目标 | 倍率 | T90（毫秒） | 目标窗口收到点击（松手后毫秒） |
| --- | ---: | ---: | ---: |
| 普通桌面 | 1× | 304 | 941 |
| 普通桌面 | 3× | 102 | 332 |
| 普通桌面 | 4× | 77 | 257 |
| 全屏 App 所在空间 | 1× | 301 | 953 |
| 全屏 App 所在空间 | 3× | 100 | 333 |
| 全屏 App 所在空间 | 4× | 77 | 262 |

- **0.1.1** 修复了接近目标时先停住、再滑一小段的问题。旧版曾提前约 175 点结束手势。修复后用触控板做了四次约 2× 的切换，T90 为 151 至 157 毫秒，结束事件发出时距落点 0 至 1 点。
- **0.1.2** 的慢划收尾在 1× 和 3× 下分别为 314 和 106 毫秒，停住再松手分别为 312 和 104 毫秒。取消后回弹在 1× 和 4× 下分别为 316 和 77 毫秒，两次都回到原桌面。以上均为 T90。
- **0.1.4** 修复了连续回切时回程退回原速的问题。在 3× 下，去程松手后约 60、150、230 毫秒开始反向划动，均回到起始桌面。回程 T90 从修复前约 310 毫秒降到约 100 毫秒。
